I built two Claude Code plugins for a question I could not answer about my own plugins: does this actually help, or does it only feel like it?

Optimizer opens two paired Claude Code sessions on the same task, one with the plugin and one without, same model, same seed files, same opening prompt, and you work both of them like normal work. Definition-of-Done checks are written before either session starts, and it ends with one report built from both transcripts: quality, tokens, turns, autonomy. If you type a prompt into one session and not the other, that gets recorded as a bias indicator rather than ignored.

Prospector is the other half, for before you build: it interviews you about what you actually did, checks whether something already solves it, and ships narrow MVPs you use on real work until a direction holds.

Free and MIT, Windows, macOS, Linux: https://github.com/tommasomazieri/plugin-rnd-lab

It is early and I would rather have it torn apart than praised. There is a feedback form linked in the README, mostly clicks, and stopping halfway counts as an answer.
