Description:
A marketplace of R&D tooling for Claude Code plugins. Optimizer runs a plugin against a paired control session on the same task, with the operator working both arms, and reports quality, tokens, turns and autonomy against Definition-of-Done checks written before the run. Prospector covers the stage before that, interviewing for real behaviour and shipping narrow MVPs until a direction holds.
